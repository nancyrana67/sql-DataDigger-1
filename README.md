# DataDigger

> A simple MySQL database project for managing customers, orders, products, and order details.

---

## 📌 Project Overview

**DataDigger** is a relational database project built using **MySQL**.

The project demonstrates how a basic business database can be designed and managed using SQL. It covers customer management, order tracking, product management, and order details while using important SQL concepts such as:

- Database and table creation
- Primary keys
- Foreign keys
- Data insertion
- Data updating
- Data deletion
- Data filtering
- Sorting
- Aggregate functions
- Grouping
- Joins
- Subqueries

The project is suitable for learning and demonstrating fundamental SQL and database management concepts.

---

## 🎯 Project Objectives

The main objectives of DataDigger are:

1. Create a structured relational database.
2. Store and manage customer information.
3. Track customer orders.
4. Maintain product information and stock.
5. Connect orders with products.
6. Perform useful data analysis using SQL queries.
7. Demonstrate relationships between multiple tables.
